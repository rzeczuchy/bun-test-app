bun test app API

version 1.0.0OpenAPI 3.0.3

REST API for the bun test app.

Authentication

- Log in with POST /api/auth/login to get an access token, then send it as Authorization: Bearer <token>. - POST /api/admin/users does not use a token. It takes the admin's username and password as HTTP Basic auth.

POST /api/auth/logout

Log out
Auth

Revokes the access token on the server. Always returns 204, including when the token is missing, expired or already revoked, so it is safe to call twice.
